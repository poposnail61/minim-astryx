# Minim 전체 컴포넌트 검수 기록

검수일: 2026-09-26. 최초 검수 후 사용자 피드백에 따라 아래 항목을 수정·재확인했다. 뒤쪽 전수 목록은 최초 검수 시점의 기록이다.

## 후속 수정 결과

- **TextInput:** 16개 변형의 제목을 지정된 [field/field-label](https://www.figma.com/design/mHcauYaYWK3floQNsfolz6?node-id=10322-32134) 인스턴스로 교체했다. 입력 내용용 slot-label-content를 제목에 사용하던 부분을 수정했다. 제목 20px + 설명 16px = Base 36px이며, 기존 코드의 공통 Field와 일치한다. has-label 연결과 제목 문구는 보존했다. [수정 컴포넌트](https://www.figma.com/design/mHcauYaYWK3floQNsfolz6?node-id=10322-35557)
- **Slider:** 14개 변형도 같은 field-label로 교체했다. 일반 상태만 있던 바깥 8px 패딩을 제거해 코드와 동일하게 맞췄다. 오류·경고·성공 여부와 무관하게 트랙 시작점은 Base y=40, Compact y=36이다. 트랙은 가로로 늘어나고 손잡이는 20px을 유지하며 값 위치에 비례해 움직인다. 눈금과 말풍선에도 같은 위치 기준을 적용했다. 말풍선 겹침 자체는 사용자 요청대로 수정 대상에서 제외했다. [피그마](https://www.figma.com/design/mHcauYaYWK3floQNsfolz6?node-id=10542-38446) · [코드 예시](http://localhost:5181/components/Slider)
- **StatusDot:** [Astryx 원본 피그마](https://www.figma.com/design/6j79u8VjyyjdV4vURveP9A?node-id=9-3509)의 pulsing 변형에도 blur 4px, spread 2px, opacity 50% 번짐이 있다. 반면 저장소의 upstream/main(a4bcbeb026ae6904a962d9b1eab4715fe3b73ab4) 코드는 opacity 1 → 0.5 → 1 애니메이션이다. Minim에서 새로 생긴 누락이라고 단정할 수 없어 양쪽 표현을 유지했다.
- **OverflowList:** Compact의 실제 간격은 6px인데 기존 계산은 8px이었다. 실제 CSS 간격을 측정하고 항목 너비의 소수점을 보존하도록 수정했다. 여러 줄 높이 계산에도 측정 간격을 사용한다. 예시 3곳의 바깥 너비도 안정적으로 지정해 항목을 숨길 때 부모가 함께 줄어들지 않도록 했다. [예시](http://localhost:5181/components/OverflowList)
- **AvatarGroup:** 중복된 속성이 아니라 서로 다른 두 컴포넌트 세트의 이름이 모두 avatar였던 문제다. 그룹 15개 변형을 가진 세트만 avatar-group으로 변경했다. 인스턴스 연결·크기·디자인은 유지했다. [피그마](https://www.figma.com/design/mHcauYaYWK3floQNsfolz6?node-id=10481-29438)
- **ToggleButton:** 실제 Button이 내보내는 data-content는 정상이지만 테마 설명의 visualProps에 content가 누락돼 있었다. 정의에 추가했고 아이콘 전용 디자인이나 동작은 바꾸지 않았다. 테마 빌드에서 해당 속성 경고가 사라진 것을 확인했다. [예시](http://localhost:5181/components/ToggleButton)
- **내부 guide:** 속성-1 → variant, 기본/베리언트2/베리언트3 → grid/outline/wide로 변경했다. 아이콘 제작용 내부 가이드이며 외곽 치수와 그림은 그대로다. [피그마](https://www.figma.com/design/mHcauYaYWK3floQNsfolz6?node-id=6414-27335)

후속 검증: 관련 단위 테스트 163개와 TypeScript 검사 통과. 브라우저 회귀 테스트 2개(OverflowList 밀도 반복 전환, Slider 너비·상태별 위치)도 통과했다. 개발 서버 컴파일 중 한 차례 예시 로딩 시간 초과가 있었으며 로딩 후 재실행으로 확인했다. 피그마 Slider 14개 변형 × Base/Compact × 200/420px 너비의 56개 조합에서 트랙 너비, 값 위치, 손잡이 크기 검증 통과. 임시 검증 인스턴스는 모두 제거했다. 테마 빌드 완료(폰트 파일을 앱에서 로드하라는 기존 안내는 별도).

## 후속 시각 검수

수치 검사와 별도로 TextInput, Slider, OverflowList, AvatarGroup, ToggleButton, StatusDot의 실제 렌더링을 PC 1440px·모바일 390px, Base·Compact에서 24개 캡처로 확인했다. Slider 상태 메시지는 추가 확대 캡처로 확인했고, 최신 피그마 TextInput·Slider 변형 이미지와 대조했다. 이번 범위가 전체 컴포넌트·전체 상태 시각 검수 완료를 뜻하지는 않는다. 제품 코드와 피그마는 이 시각 검수 단계에서 추가 수정하지 않았다.

### 시각 검수 후 수정

- 분리형 성공 메시지도 `fg/primary` / `bg/primary`를 사용하도록 테마와 배포용 템플릿을 수정했다. 아이콘은 같은 색을 상속한다.
- 모바일 OverflowList 미리보기만 실제 화면 너비를 사용하게 변경했다. 다른 컴포넌트의 고정 너비 미리보기에는 영향을 주지 않는다.
- 피그마 비활성 Slider 두 변형의 손잡이 3개를 `bg/primary-solid`에 연결했다. 기존 20px 크기, 위치, 상위 비활성 투명도는 유지했다.
- 관련 단위 테스트 49개 통과. 모바일 잘림 방지와 Base·Compact 성공 메시지/아이콘 색상 브라우저 검증 통과.
- 수정 후 모바일 Base·Compact OverflowList와 성공 메시지를 직접 캡처해 시각 확인했다. 별도 브라우저 검증 2개 통과. 전체 회귀 실행은 후속 기존 예시 로딩 지연으로 중단했으므로 전체 통과로 계산하지 않았다.

### 확인한 정상 부분 (수정 전 검수)

- TextInput 대표 화면: Base·Compact 제목과 입력 텍스트 정렬, 좁은 화면 여백, 테두리 잘림 없음. 피그마 제목 교체 후 변형별 라벨·설명 정렬도 확인.
- Slider: 일반·상태 메시지 예시의 트랙과 라벨 정렬 정상. 값 말풍선 겹침은 사용자 요청대로 결함 대상에서 제외.
- AvatarGroup: 이름 변경 후 아바타 겹침·원형 테두리·오버플로 숫자 정상.
- ToggleButton: 아이콘 전용·텍스트 혼합 및 선택 상태의 높이와 중앙 정렬 정상.
- StatusDot: 대표 점 정렬 정상. 원본부터 존재한 피그마 번짐/코드 투명도 표현 차이는 이전 기록 유지.

## 검증 범위와 한계

- 코드 문서 등록부의 공개 core 항목 179개를 대상으로 했다. Provider와 하위 구성 요소도 포함하고 hook 및 hidden 항목은 제외했다.
- 현재 수집한 페이지 179개, Base·Compact 화면 358개. 대표 화면 캡처와 렌더 오류, 가로 넘침, 계산된 스타일을 기록했다.
- 독립 대표 예시가 있는 항목 158개, 없는 항목 21개. 179개 페이지의 최종 탐색에서 HTTP 오류·브라우저 pageerror·페이지 가로 넘침은 발견되지 않았다.
- 피그마 12개 컴포넌트 페이지, 컴포넌트 세트/독립 컴포넌트 194개를 구조 검사했다. 기존 OS 재료가 남아 있는 component v2도 별도 목록에 포함했다.
- 피그마 구조 검사는 변형 이름 중복, 공개 속성명, 매우 작은 표시 텍스트 등을 확인한 것이다. 모든 토큰 연결과 모든 숨겨진 속성 조합의 의미까지 자동으로 보장하는 검사는 아니다.
- 브라우저 대표 화면은 Base·Compact PC 크기 기준이다. 모든 변형·모바일·키보드·스크린리더 조합의 전수 시각/동작 검수 완료를 의미하지 않는다. 메뉴/팝오버가 닫힌 대표 화면만 있는 항목은 열린 상태의 검증을 대신하지 않는다.
- 테마 단위 테스트: 18개 파일, 94개 테스트 통과.
- 메뉴 PC·모바일 동작 테스트는 개발 서버 페이지 로딩 시간 초과로 중단했다. 동작 실패로 확정하지 않았으며 통과로도 계산하지 않았다.
- 이 표의 페이지 확인은 디자인 승인 표시가 아니다. 독립 예시가 없는 항목은 미검수로 구분했다. 이름이 같은 피그마 링크는 대조 후보이며 일대일 연결 확정이 아니다.
